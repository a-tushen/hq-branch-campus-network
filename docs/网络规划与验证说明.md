# 企业总部—ISP—分支 双核心高可用综合实验

## 一、如何导入

1. 打开 eNSP → 菜单 **文件 / File → 打开** → 选择
   `topology/企业总部—ISP—分支双核心高可用综合实验.topo`。
2. 全选设备右键 **启动**（共 24 台，首次启动约 3～5 分钟）。
3. 逐台双击进入 CLI，把 `configs/<设备名>.txt` 全文粘贴进去。
4. 每台配置完执行 `save` → `y` 保存。

> 终端（PC / Server / Client）地址已写在 .topo 里，启动后即生效；
> PC1、PC2、AP1、STA1 设为 DHCP 获取。

## 八、需求实现对应关系

| 题目要求 | 实现方式 | 落点 |
|---|---|---|
| 每个终端一个 VLAN | VLAN 10/20/30/40/50，接入端口 access 划分 | LSW1、LSW2、LSW5 |
| PC1 网关在 LSW3、PC2 在 LSW4，互为主备 | VRRP vrid 10/20/30，LSW3 优先 VLAN10/30，LSW4 优先 VLAN20 | LSW3、LSW4 Vlanif |
| PC/AP/STA 由 DHCP 下发 | 独立 DHCP 服务器 + 各网关上 `dhcp select relay` | DHCP、LSW3、LSW4 |
| 总部服务器被公网与分支访问 | FW1 `nat server` 发布 200.1.1.10:80 | FW1 |
| 分支终端网关在路由器 | AR4 Eth-Trunk1 上起 .10/.20/.30 子接口 + `dot1q termination` | AR4 |
| 路由器与交换机链路聚合备份 | AR4 与 LSW5 之间 LACP Eth-Trunk1（2 成员口） | AR4、LSW5 |

## 十、配置要点

| 设备 | 要点 |
|---|---|
| FW1 | 接口与安全域、默认路由、源NAT（easy-ip）、NAT Server 发布服务器、安全策略 |
| LSW2 | 核心交换：服务器/管理/互联 VLAN 网关，到网关双机的静态路由与默认路由 |
| LSW3 | VLAN10/30 的 VRRP 主 + VLAN20 备；MSTP 实例1根桥；DHCP 中继 |
| LSW4 | VLAN20 的 VRRP 主 + VLAN10/30 备；MSTP 实例2根桥；DHCP 中继 |
| LSW1 | 接入交换：PC1/PC2/AP 划分 VLAN，双上行 trunk，边缘端口 |
| DHCP | 全局地址池 3 个（VLAN10/20/30），网关指向 VRRP 虚地址 |
| AC1 | CAPWAP 源接口、SSID/安全模板/VAP 模板、业务 VLAN 30、AP 免认证上线 |
| AR1 | ISP 边缘：到总部公网互联 + OSPF |
| AR2 | ISP 核心：三方向互联 + 公网服务器区网关 + OSPF |
| AR3 | ISP 边缘：到分支公网互联 + OSPF |
| LSW6 | 公网服务器区接入：VLAN200 |
| AR4 | 分支网关：Eth-Trunk 上起 dot1q 子接口作为三 VLAN 网关 + 源NAT + 默认路由 |
| LSW5 | 分支接入：Eth-Trunk 双链路聚合，三个 VLAN 接入端口 |

## 十一、注意事项

1. **防火墙型号**：本拓扑用 `USG5500`（本机实测可正常加载，接口为 `GE0/0/0`～`GE1/0/8`）。若要换 `USG6000V`，把设备型号换掉、并在 `FW1.txt` 中把接口名按实际显示统一即可（配置逻辑不变）。
2. **防火墙登录**：`USG5500` 默认 `admin` / `Admin@123`；`USG6000V` 首次登录会强制改密码。
3. **无线部分**：AP1 需 `ap auth-mode no-auth` 免认证上线；STA1 搜索 SSID `HQ-WLAN`，密码 `Huawei@123` 关联。
4. **VRRP 与 STP 已对齐**：VLAN10/30 的根桥与 VRRP 主都在 LSW3，VLAN20 都在 LSW4，避免流量绕行。
5. **链路聚合**：两端都要 `mode lacp-static`，AR4 侧先建 Eth-Trunk 再加入物理口，分支网关子接口必须带 `arp broadcast enable`。
6. **防火墙命令差异**：`USG5500` 用接口下 `nat outbound 2000` + 系统视图 `nat server`。若该版本不支持 `security-policy` 视图（V300 早期用 `policy interzone`），可跳过安全策略那段——此时默认策略为 permit，实验连通性不受影响，但答辩时应说明这是未收紧的配置。
7. **eNSP 版本差异**：若某条命令报错，多为该版本不支持，可跳过并在报告中说明。
